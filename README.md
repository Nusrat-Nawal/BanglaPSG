# BanglaPSG

BanglaPSG is a Bangla public grievance dataset developed to support research on automated public grievance analysis in Bangladesh.

This repository contains the baseline implementations and experimental notebooks accompanying the BanglaPSG dataset.

---

## Dataset

The BanglaPSG dataset is publicly available through **Mendeley Data**.

**Dataset DOI**
https://doi.org/10.17632/w6c4zx5t2s.1

The dataset is **not included in this repository**. Please download it from Mendeley Data before running the notebooks.

---

## Dataset Summary

- Language: Bangla
- Total Samples: 6,105
- Categories: 6
- Severity Levels: 3 (Low, Medium, High)

### Categories

- Healthcare
- Road & Transport
- Water
- Waste
- Food
- Electricity

---

## Baseline Models

This repository includes baseline implementations for:

- SVM
- BanglaBERT
- mBERT
- XLM-R

for both

- Category Classification
- Severity Classification

These baseline models are provided to facilitate reproducibility and future research using the BanglaPSG dataset.
